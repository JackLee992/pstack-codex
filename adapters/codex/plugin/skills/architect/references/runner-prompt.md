# Independent design brief

The coordinator supplies the user goal, surrounding source, constraints, and authorized deliverable. Propose a data shape, caller usage, interfaces, ownership, and failure/cleanup sequence that meets that scope. Cite existing components to reuse and the specific code a change must touch.

Compare a meaningful alternative when it changes the tradeoff. Explain complexity hidden behind each interface and how a maintainer can verify the choice. Do not edit implementation, install dependencies, or expand the task unless assigned those actions. Return assumptions and unresolved requirements separately from the design.
